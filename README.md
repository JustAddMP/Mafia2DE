# Mafia II: Definitive Edition — Co-op

**Status: early work.** The first build puts a CO-OP entry into the game's own main and pause menus (the game
draws the CO-OP page itself, in its own style); hosting and joining do not work yet. Tested in game on 2026-10-18:
the main menu's CO-OP entry and page work and look like the game's own menus; the pause menu is not tested yet.

This will be a co-op mod for Mafia II: Definitive Edition, built on the shared
[JustAddMP core](https://github.com/JustAddMP/core) framework, the same way as
[Mafia: Definitive Edition — Co-op](https://github.com/JustAddMP/MafiaDE).

Developers: [README-dev.md](README-dev.md) (build, launch, test), [docs/PLAN.md](docs/PLAN.md),
[docs/re-notes.md](docs/re-notes.md).

Follow progress on [justaddmp.com](https://justaddmp.com).
